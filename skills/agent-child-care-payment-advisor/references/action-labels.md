## Format

`[Verb] [2-4 word object] — [qualifier]`

- Qualifier is a count or scope only (e.g. `23 children`, `55 days`); omit the dash and qualifier entirely when there is nothing to count.
- Use an em dash (`—`, U+2014), not a plain hyphen, matching the actual rendered output in both `server.ts` and `next_action_ranking.py`. When editing either file in an environment without reliable UTF-8 round-tripping (e.g. a shell pipeline), verify the byte value after saving rather than assuming a hyphen substitute is equivalent.
- No trailing punctuation. Sentence case. No parenthetical reason.

## Verb vocabulary (fixed set — never substitute a synonym)

| Verb | Used for |
| --- | --- |
| Review | Opens a detail/drill-down view of a named risk or exception |
| Open | Opens a named summary or page that is not itself a risk review |
| Compare | A by-county or by-child breakdown of the same underlying data |
| Retry | Re-runs a blocked or failed capability |

`Confirm` is never used as an action verb. Parent confirmation of attendance happens in the parent portal, not by the provider or by this agent — the provider can only **review** which days are pending, confirmed, or outside the confirmation window. A label that reads "Confirm ..." implies the provider (or the agent, on the provider's behalf) can complete the confirmation, which is false and must never be rendered.
